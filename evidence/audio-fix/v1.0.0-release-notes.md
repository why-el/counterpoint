Counterpoint is a 3D music box with eight resonators and a flywheel that controls time. Marble strikes play synthesized notes after Sound is enabled. It supports touch, keyboard controls, and shared arrangements.

[Open Counterpoint](https://why-el.github.io/counterpoint/). The existing Pages custom domain is [wael.khobalatte.com](https://wael.khobalatte.com/counterpoint/).
